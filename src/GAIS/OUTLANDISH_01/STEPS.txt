Here is the exact, step-by-step walkthrough to get `y-cruncher` running on your Windows machine and produce your first test files.

---

### Step 1: Download & Extract `y-cruncher`

You can do this right inside your open VS Code terminal.

1. **Download the zip file:**
   Run this command in your terminal (Windows 11 includes `curl` natively):
   ```cmd
   curl -L -o y-cruncher.zip "https://github.com/Mysticial/y-cruncher/releases/download/v0.8.5.9543/y-cruncher.v0.8.5.9543.zip"
   ```
   *(If `curl` is blocked or fails, simply open [y-cruncher on GitHub Releases](https://github.com/Mysticial/y-cruncher/releases) in your web browser, download the `.zip` file, and move it into your `GAIS` folder).*

2. **Extract the archive:**
   Run this in your terminal (Windows 11 includes `tar` natively):
   ```cmd
   tar -xf y-cruncher.zip
   ```

3. **Check your folder:**
   Run:
   ```cmd
   dir
   ```
   You will now see a subfolder named something like `y-cruncher v0.8.5.9543`.

---

### Step 2: Generate the $10^6$ Digits Text Files

`y-cruncher` has an interactive text menu that takes about 10 seconds to navigate.

#### Generating $\pi$ ($10^6$ digits):
1. In your terminal, launch the program:
   ```cmd
   cd "y-cruncher v0.8.5.9543"
   y-cruncher.exe
   ```
2. A console window will appear with options. Type these keys, pressing **Enter** after each:
   * Select **`0`** (Custom Compute)
   * Select **`1`** (Pi)
   * It will ask for the number of digits. Type: **`1m`** (or `1000000`)
   * For computation mode / memory, keep pressing **Enter** to accept the defaults.
   * When asked to start computation, press **Enter**.
   * It will finish in ~0.05 seconds!
   * Look at the message: it writes the output file named **`Pi - Dec - Chudnovsky.txt`** right inside that `y-cruncher` folder.
   * Press **`q`** to return to the main menu.

#### Generating the Golden Ratio $\phi$ ($10^6$ digits):
1. Still inside the `y-cruncher` menu:
   * Select **`0`** (Custom Compute)
   * Select **`4`** (Golden Ratio)
   * Enter digits: **`1m`**
   * Press **Enter** through defaults until it computes.
   * It writes a file named **`Golden Ratio - Dec - Newton.txt`**.
   * Press **`q`** and then **`0`** to exit `y-cruncher`.

2. **Move back to your `GAIS` folder:**
   ```cmd
   cd ..
   ```

---

### Step 3: Create the Binary Converter Script

The text files generated by `y-cruncher` have headers (e.g., date, computation time, "3.") followed by ASCII characters `'0'` through `'9'`. 

We will create a small script, `convert_digits.py`, to strip headers and save pure unsigned byte values `0x00` to `0x09`.

1. In VS Code, create a file named **`convert_digits.py`** in `src/GAIS`:

```python
import os
import glob

def clean_and_convert(txt_path, bin_path, max_digits=1_000_000):
    print(f"Reading {txt_path}...")
    
    # Translation table: converts ASCII '0'..'9' (0x30..0x39) to raw byte values 0x00..0x09
    table = bytes.maketrans(b"0123456789", bytes(range(10)))
    
    digits_collected = bytearray()
    
    with open(txt_path, "rb") as fin:
        for line in fin:
            # y-cruncher text files put digits in lines starting with a number
            # Skip empty lines or header metadata lines
            line = line.strip()
            if not line or not (48 <= line[0] <= 57):
                continue
                
            # Filter only numeric ASCII characters (ignoring spaces or decimal points)
            numeric_chars = bytes([b for b in line if 48 <= b <= 57])
            # Convert to raw byte values 0x00..0x09
            digits_collected.extend(numeric_chars.translate(table))
            
            if len(digits_collected) >= max_digits:
                break
                
    # Trim to exact target length
    final_data = digits_collected[:max_digits]
    
    with open(bin_path, "wb") as fout:
        fout.write(final_data)
        
    print(f"-> Successfully created {bin_path} ({len(final_data):,} bytes)")

if __name__ == "__main__":
    # Find the y-cruncher folder dynamically
    yc_folders = glob.glob("y-cruncher*")
    if not yc_folders:
        print("Error: Could not find y-cruncher folder!")
        exit(1)
        
    yc_dir = yc_folders[0]
    
    # 1. Convert Pi
    pi_txt = glob.glob(os.path.join(yc_dir, "Pi*.txt"))
    if pi_txt:
        clean_and_convert(pi_txt[0], "digits_pi_10_to_6.bin", 1_000_000)
    else:
        print("Pi text file not found! Did you run y-cruncher for Pi?")
        
    # 2. Convert Golden Ratio
    phi_txt = glob.glob(os.path.join(yc_dir, "Golden Ratio*.txt"))
    if phi_txt:
        clean_and_convert(phi_txt[0], "digits_golden_ratio_10_to_6.bin", 1_000_000)
    else:
        print("Golden ratio text file not found! Did you run y-cruncher for Golden Ratio?")
```

2. **Run the script in your terminal:**
   ```cmd
   python convert_digits.py
   ```

### Step 4: Verify the Results

Run:
```cmd
dir
```
You should see:
* `digits_pi_10_to_6.bin` — exactly **1,000,000 bytes**
* `digits_golden_ratio_10_to_6.bin` — exactly **1,000,000 bytes**

To confirm the binary content is correct, run a quick one-line inspection in Python:
```cmd
python -c "data = open('digits_pi_10_to_6.bin', 'rb').read(10); print(list(data))"
```
You should see:
```python
[1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
```
*(The first 10 decimal digits of $\pi$ after the 3: `1, 4, 1, 5, 9, 2, 6, 5, 3, 5` as raw byte integers).*

Once you have these two files sitting in your `GAIS` folder, you are ready to plug in the lottery matching script.
