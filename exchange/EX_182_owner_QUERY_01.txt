## **The i5-4670 may still be very useful**

There is an important distinction between **PyPI packages** (the Python package repository) and **PyPy** (an alternative Python interpreter).

For ordinary PyPI installations, many packages provide precompiled Windows x64 wheels. Those do not require installing Visual Studio or compiling their source.

We can deliberately use:

```
python -m pip install --only-binary=:all: package_name
```

This instructs pip to use prebuilt distributions rather than building from source. If no compatible wheel exists, installation fails rather than attempting a compilation.

We would check compatibility with the installed Python version before selecting packages. In particular, we shouldn't assume every scientific package already supports Python 3.15.

Also, **VS Code is not required to execute Python scripts**. We can develop on the Ryzen, then transfer scripts and run them from CMD on the i5. A virtual environment on the i5 is optional and can be created without Visual Studio.
